# Gallery media

Add the photos and videos for the website gallery here. The site build reads these folders, so no code changes are needed.

- `photos/` : JPG, PNG or WebP. Any size; they are resized automatically.
- `videos/` : MP4 (H.264). Keep each video short and under 25 MB.

Tips
- File names become the display order (for example `01-opening.jpg`, `02-games.jpg`).
- Only add media that has consent to be published.
- Optional: add `captions.json` in this folder to give items a caption and description in English and Tibetan.
